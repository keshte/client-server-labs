## 1. Опис проєкту
Сервіс `Real-Time Operations Gateway` поєднує два взаємодоповнюючі режими передачі даних реального часу:
* **Рівень 1 (Базовий):** однонапрямлений SSE-потік метрик сервера (`GET /api/v1/metrics/stream`) з підтримкою `http.Flusher`, щосекундним оновленням пам'яті (`runtime.MemStats`) та кількості горутин (`runtime.NumGoroutine()`), а також запобіганням витоку пам'яті через `r.Context().Done()`.
* **Рівень 2 (Ключовий):** повнодуплексний WebSocket сервер на Gorilla WebSocket (`GET /api/v1/ws`) з архітектурним патерном `Hub`, розпаралеленими горутинами вичитування (`readPump`) і потокобезпечного запису (`writePump`).
* **Рівень 3 (Просунутий):** підтримка ізольованих кімнат (`rooms`: alerts, general, ops), Heartbeat Ping/Pong для виявлення розривів та повноцінна інтерактивна веб-панель (`web/index.html`).

## 2. Інструкція запуску та перевірки

### Запуск сервісу:
```bash
go run main.go
```
Сервіс запускається на порті `:8080`.

### Перевірка через веб-інтерфейс:
Відкрийте у браузері (можна у двох різних вкладках):
[http://localhost:8080/](http://localhost:8080/)
* У лівому блоці автоматично транслюються метрики через SSE.
* У правому блоці можна перемикати кімнати (`alerts` / `general`), відправляти повідомлення та бачити ізоляцію трафіку між кімнатами.

### Перевірка потоку SSE в терміналі:
```bash
curl -N http://localhost:8080/api/v1/metrics/stream
```

### Запуск автоматичних тестів:
```bash
go test -v
```
Тести підтверджують роботу SSE та 100% ізоляцію кімнат WebSocket.
