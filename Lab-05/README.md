## 1. Опис проєкту
Сервіс `Incident Tracker API` реалізує бекенд оперативного обліку технічних інцидентів та аварій відповідно до вимог трьох рівнів:
* **Рівень 1 (Базовий):** вебсервер на базі `Gin`, автоматична міграція моделей через `GORM`, валідація вхідних DTO (`go-playground/validator`), робота з інцидентами.
* **Рівень 2 (Ключовий):** завершення повного циклу CRUD, сутність користувача (`User`), криптографічне хешування паролів `bcrypt` та випуск JWT токенів (`golang-jwt/jwt/v5`).
* **Рівень 3 (Просунутий):** власний перехоплювач `AuthMiddleware` для захисту приватних маршрутів (POST, PATCH, DELETE) та інтерактивна документація `Swagger UI`.

## 2. Інструкція із запуску

### Запуск сервісу:
```bash
go run main.go
```
Сервіс автоматично підключається до бази даних (PostgreSQL або локальний fallback SQLite) та запускається на порті `:8080`.

### Перевірка документації:
Відкрийте у веббраузері:
[http://localhost:8080/swagger/index.html](http://localhost:8080/swagger/index.html)

### Запуск автоматичних тестів:
```bash
go test -v
```
Усі тести рівнів 1–3 успішно виконуються з результатом `PASS`.
